Sistem Prompt Çıkarma Teknikleri
Sistem prompt'un çıkarılması, bir LLM'nin (Large Language Model; Büyük Dil Modeli) davranışını, kişiliğini, kurallarını ve yeteneklerini tanımlayan gizli talimatları ortaya çıkarması için kandırılması işlemidir. Sistem prompt, uygulama geliştiricisi tarafından modelin context window'una (bağlam penceresine) yüklenen ilk talimat kümesidir. Genellikle iş mantığı, güvenlik kuralları, dahili API uç noktaları, araç açıklamaları ve guardrail yapılandırmaları dahil olmak üzere hassas bilgiler içerir. Sistem prompt sızıntısı, Open Worldwide Application Security Project (OWASP) LLM Top 10'da LLM07 olarak sınıflandırılmıştır.

Sistem Prompt'lar Neden Önemlidir
Sistem prompt'lar LLM uygulamalarının "kaynak kodu" gibidir. Kaynak kodunun derlenmiş binary'ye dönüştüğü geleneksel yazılımlardan farklı olarak sistem prompt, her etkileşim sırasında modelin context window'u içinde düz metin olarak bulunur. Bir saldırgan sistem prompt'u çıkarırsa şunları elde eder:

İş mantığına maruz kalma: Uygulamanın altında çalıştığı kesin kuralları ve kısıtlamaları anlamak.
Güvenlik kuralı eşleme: Modele ne yapmaması söylendiğini tam olarak bilmek; bu bilgi bypass payload'ları hazırlamayı kolaylaştırır.
Dahili altyapı keşfi: Sistem prompt'ları genellikle API endpoint'lerini, veritabanı adlarını ve dahili araç açıklamalarını içerir.
Kimlik bilgilerinin açığa çıkması: Kötü tasarlanmış sistem prompt'lar API anahtarları, kimlik doğrulama tokens veya dahili şifreler içerebilir.
Saldırı yüzeyi haritalaması: Araç açıklamaları ve işlev tanımları, hedeflenebilecek entegrasyon noktalarını ortaya çıkarır.

Sistem Prompt Çıkarma Girişimlerini Algılama
Extraction girişimlerinde sık görülen göstergeler şunlardır:

Anahtar kelimeler: sistem prompt, talimatlar, yapılandırma, ilk mesaj, kurallar, yönergeler

Kodlama istekleri: base64, ROT13, reverse, geriye doğru, kodla, [alışılmadık dile] çevir

Yetki iddiası: Geliştirici benim, yönetici modu, diagnostic mode, debug mode, maintenance mode

Format değişikliği: JSON olarak, kod olarak, kod bloğunda, yapılandırma dosyası olarak, XML olarak

Kademeli araştırma: Yetenekleri, kuralları ve kısıtlamaları sırayla soran çok sayıda kısa soru

Detection yaklaşımı:

Kullanıcı input'unda bu pattern'leri izleyin
Conversation trajectory'leri takip edin ve gradual probing davranışını tespit edin
Model çıktısında başarılı extraction bulgularına alarm üretin
Extraction niyetini tespit etmek için classifier kullanın

Temel Çıkarımlar
Sistem prompt'lar, LLM uygulamalarının "kaynak kodu" gibidir ve genellikle API anahtarları, dahili endpoint'ler ve iş mantığı dahil olmak üzere hassas bilgiler içerir.
Doğrudan çıkarma teknikleri (yalnızca prompt istemek) zayıf korunan uygulamalara karşı işe yarar.
Dolaylı teknikler (davranışsal çıkarım, kodlama hileleri, çok turlu çıkarım) basit savunmaları aşabilir.
Temel güvenlik açığı mimaridir: sistem prompt, kullanıcı girdisiyle aynı context window içinde düz metin tokenları olarak bulunur.
Savunma birden fazla katman gerektirir: input filtering, output monitoring, sistem prompt sağlamlaştırma ve sistem prompt'larda hassas veri saklamaktan kaçınma.
